# ☕ Programação Orientada a Objetos em Java

## Descrição
Disciplina que apresenta os conceitos básicos de Programação Orientada a Objetos (POO) utilizando a linguagem Java, com foco na criação de sistemas organizados e reutilizáveis.

## Conteúdo
- Classes e objetos  
- Atributos e métodos  
- Construtores  
- Encapsulamento  
- Herança  
- Polimorfismo  

## Objetivo
Capacitar o aluno a desenvolver programas em Java aplicando os princípios da orientação a objetos.

- Lógica de programação básica
